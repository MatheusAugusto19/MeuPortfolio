## 🛠️ Tecnologias Utilizadas

* **Vite** - Build tool rápida e moderna
* **HTML5 & CSS3/SASS** - Estrutura semântica, responsividade e layout moderno
* **JavaScript (ES6+)** - Manipulação dinâmica do DOM e i18n (Troca de Idiomas)
* **AOS (Animate On Scroll)** - Animações suaves de rolagem
* **Boxicons** - Ícones vetoriais modernos
